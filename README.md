## 项目简介

Apologia-ui**以意图为核心的界面AI 生成技能**。

针对当前 AI 生成 UI 普遍「重美化、轻引导」的痛点，我提出「苏格拉底美学」的设计哲学 —— 美是功能的副产品，界面的首要使命是回答用户三个终极问题：

- 我现在在哪？（从哪来）
- 我要做什么？（到哪去）
- 我怎么回去？（回哪去）

让用户拿到界面的第一秒，就知道该怎么操作。


## 基础设计原则

### 1. 「从哪来」原则：位置感优先
### 2. 「到哪去」原则：主意图视觉权重最高
### 3. 「回哪去」原则：闭环导航
