# 导航 Navigation

顶部导航、面包屑、返回路径。

## 1. 意图归属

导航只在用户**需要知道自己身处何处**时才该存在。它主要服务两类意图：

| 意图 | 导航承担的职责 |
|---|---|
| 核验 | 提供「为什么我会看到这个」的解释链 |
| 寻的 | 提供横向切换的入口与当前栏目定位 |

**判据：如果一个界面只有单一入口、无横向并列项、无上级层级，那么它不需要导航，加导航即为噪音。**

服务「续接」意图时，导航须保留用户上次所在位置并高亮，不允许每次回到默认项。

## 2. 形态必然性

### 推导一：面包屑必须逐级可点

- **意图**（核验）：用户从通知或深链直跳进深层页面，他需要确认「我为什么在这里、这里归属于谁」。
- **推导**：来路不可见 → 用户无法为当前视野建立上下文 → 他只能靠记忆猜测自己在哪一层。
- **结论**：面包屑显示完整层级链，每一级可点，最后一级为当前页。

### 推导二：物理路径必须如实反映心智来历

- **意图**（从哪来）：用户的「来」是触发他的那件事，不是空白起点。
- **推导**：用户从通知直跳进来时，如果面包屑显示空白或与来源无关的层级，等于抹掉了他的动机来历。
- **结论**：面包屑反映的是**这条数据真实的归属链**，不是浏览器历史。

### 推导三：层级 ≥ 3 时必须同时给两条出路

- **意图**（回哪去）：用户既要退回最近一步，也要能一跳回到安全锚点。
- **推导**：只给「上一级」时，位于第 5 层的用户需要点 4 次才能到首页，退路成本随深度线性增长。
- **结论**：三级及以上，除「返回上一级」外必须额外提供「回首页」。

### 推导四：高亮不能只靠颜色

- **意图**：当前栏目必须可被瞬间识别，且对所有人都可识别。
- **推导**：仅靠颜色时，色觉障碍用户无法区分当前项；同时颜色在强光屏幕下对比度衰减。
- **结论**：高亮 = 颜色 + 字重（或底边线），至少两种。

### 推导五：导航顺序全局固定

- **意图**（续接）：位置记忆是人类形成肌肉记忆的基础。
- **推导**：顺序随页面变化时，用户无法建立位置记忆，每次都要重新扫读。
- **结论**：导航项顺序全局唯一，不允许按页面调整。

## 3. 反证

| 拿掉 / 换掉什么 | 因果在哪一环断裂 |
|---|---|
| 拿掉面包屑 | 深层页面坐标丢失，用户必须靠记忆自建上下文，记忆一旦失效就靠浏览器后退乱撞 |
| 面包屑全灰不可点 | 退回入口消失，只剩一个装饰性标签，用户视线扫过它却得不到任何动作 |
| 用纯图标做主导航 | 图标语义不可自明，触屏无 hover 补偿，用户必须先解码图标再判断去哪 |
| 高亮只改颜色 | 色觉障碍用户与强光环境下的用户失去定位，导航退化为装饰 |
| 导航顺序随页面变化 | 位置记忆失效，每次切换都要重新扫读全表 |

## 4. 切片存档

| 项 | 值 | 生效条件 |
|---|---|---|
| 面包屑位置 | 页面标题上方 | 存在层级时 |
| 面包屑可点范围 | 除末级外全部 | 恒定 |
| 返回入口级数 | 1 级：无 ／ 2 级：返回上级 ／ ≥3 级：返回上级 + 回首页 | 按层级判定 |
| 高亮方式 | 颜色 + 字重（或底边线） | 恒定 |
| 主导航项 | 必须带文字标签 | 恒定 |
| 导航项顺序 | 全局固定 | 恒定 |

> 以上是推导结论，不是法律。当意图判读改变时，需重新走第 2 段。
