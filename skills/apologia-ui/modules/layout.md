# 布局 Layout

页面骨架、栅格、视觉权重。

## 1. 意图归属

布局是全部五类意图的**承载体**，它自身不表达意图，只负责让主意图在物理上占据最大权重。

| 意图 | 布局承担的职责 |
|---|---|
| 寻的 | 搜索/直达入口占据首屏最强位置 |
| 续接 | 首页第一屏给「继续」的落点，不是给欢迎语 |
| 核验 | 信息区面积最大，动作区最小 |
| 执行 | 只呈现当前步骤所需，其余不出现 |
| 探索 | 内容密度与出口数量优先 |

**如果布局无法回答「这个页面属于哪一类意图」，那么这个页面还没有设计完。**

## 2. 形态必然性

### 推导一：一个视图只有一个视觉主语

- **意图**：用户进入时必须立刻知道该看哪里。
- **推导**：扫读依赖落点；多个等权重区块 → 视线的第一落点不确定 → 扫读退化为逐行阅读。
- **结论**：一个视图只允许一个主区块。

### 推导二：主区块必须有明确的面积优势

- **意图**：视觉权重必须与意图权重成正比。
- **推导**：主区块与次区块尺寸相近时，用户必须阅读内容才能判断主次，多消耗一次判断。
- **结论**：主区块面积或字号至少为次区块的 2 倍。

### 推导三：层级必须存在于三档以内

- **意图**：层次可被瞬间分辨。
- **推导**：四档以上字号，相邻两档差小于 1.25 倍时，人眼无法区分，层级失效。
- **结论**：字号三档（标题 / 正文 / 辅助），相邻级差 ≥ 1.25 倍。

### 推导四：区块间距必须大于区块内间距

- **意图**：分组由空间关系表达，不由分割线表达。
- **推导**：间距相等时，元素间的归属关系不可读，用户无法判断哪些属于同一组。
- **结论**：区块间距 ≥ 区块内元素间距的 2 倍。

### 推导五：栅格用 8 基数

- **意图**：对齐秩序。
- **推导**：非基数间距累积后产生 1–3px 的错位，破坏扫读的视觉基准线。
- **结论**：所有间距为 8 的倍数。

## 3. 反证

| 拿掉 / 换掉什么 | 因果在哪一环断裂 |
|---|---|
| 所有区块做成等权重 | 第一落点不确定，用户扫读眼睛无处可停，退化为逐行阅读全文 |
| 去掉主区块的面积优势 | 必须读完文案才能判断主次，多消耗一次判断 |
| 页面无标题 | 滚动两屏后用户失去坐标，无法回答「我在哪」 |
| 字号层级压到两档 | 标题与正文不可分，信息结构不可读 |
| 区块内外间距相等 | 分组关系消失，用户无法判断元素归属 |

## 4. 切片存档

| 项 | 值 | 生效条件 |
|---|---|---|
| 栅格基数 | 8px | 恒定 |
| 每视图主区块数 | 1 | 恒定 |
| 字号档数 | 3 | 恒定 |
| 相邻字号级差 | ≥ 1.25 倍 | 恒定 |
| 主区块面积比 | ≥ 2 倍于次区块 | 恒定 |
| 区块内外间距比 | ≥ 2 倍 | 恒定 |

> 以上是推导结论，不是法律。当意图判读改变时，需重新走第 2 段。
