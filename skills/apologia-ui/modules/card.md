# 卡片 Card

卡片、列表项、栅格条目。

## 1. 意图归属

卡片主要服务「寻的」与「探索」——用户正在**扫读**，为每一条内容做「是不是我要的」的快速判断。

| 意图 | 卡片承担的职责 |
|---|---|
| 寻的 | 让用户在半秒内判断「是不是这个」，并一步进入 |
| 探索 | 提供可扫读的兴趣点，且随时可脱身 |
| 核验 | 承载结构化事实，动作降级 |

**判据：卡片不是装饰盒。扫读不需要装饰，需要的是「一次判断」的信息密度。凡是不能帮助用户完成这一次判断的元素，都是噪音。**

## 2. 形态必然性

### 推导一：整卡是一个点击目标

- **意图**（到哪去）：进入下一层的滑轨必须零阻力。
- **推导**：只有标题可点时，用户必须瞄准一个小热区，触屏上误触率高，滑轨被摩擦消耗。
- **结论**：整卡可点。

### 推导二：卡内不再放第二个同权重按钮

- **意图**：一次点击对应一个决定。
- **推导**：卡内多个同权重按钮时，用户进入卡片前就要先做一次选择——决策成本前置到了不该发生的位置。
- **结论**：卡内主操作 ≤ 1 个，其余收进「更多」。

### 推导三：三级信息差必须体现

- **意图**（核验）：扫读需要层级，不需要阅读。
- **推导**：标题、正文、辅助信息字重相同时，用户必须逐字阅读才能提取关键信息。
- **结论**：标题字重最重，辅助信息（时间、来源）最轻，差值可辨。

### 推导四：高度必须等齐

- **意图**：扫读依赖稳定的视线回归基准线。
- **推导**：卡片高低不齐时，每换一行视线都要重新寻找落点，扫读节律断裂。
- **结论**：网格内卡片高度对齐；长文本按规则截断。

### 推导五：长文本截断 + 完整内容入口

- **意图**：保持网格秩序，同时不隐藏信息。
- **推导**：自由撑高 → 网格失效；纯截断无入口 → 信息不可达。
- **结论**：截断必须伴随进入详情的路径。

### 推导六：返回必须回到原位置

- **意图**（回哪去）：确定性锚点。
- **推导**：返回后回到列表顶部、筛选条件被重置时，用户需要重新扫读并重新定位，之前的工作全部作废。
- **结论**：返回恢复滚动位置与筛选状态。

## 3. 反证

| 拿掉 / 换掉什么 | 因果在哪一环断裂 |
|---|---|
| 去掉整卡可点 | 用户必须瞄准小链接，触屏误触率上升，滑轨被摩擦消耗 |
| 卡内放 4 个同权重按钮 | 决策成本前置，与卡片本身点击竞争，用户不知道该点哪 |
| 三级信息字重相同 | 必须逐字阅读才能提取关键信息，扫读退化为阅读 |
| 卡片高低不齐 | 视线回归基准线丢失，扫读节律断裂 |
| 长文本自由撑高 | 网格失效，同屏可见条目数下降 |
| 返回重置滚动与筛选 | 用户需重新扫读并重新定位，此前工作全部作废 |

## 4. 切片存档

| 项 | 值 | 生效条件 |
|---|---|---|
| 内边距 | 16–24px | 恒定 |
| 卡间距 | ≥ 16px | 恒定 |
| 圆角 | 全局统一一套 | 恒定 |
| 标题与正文字号差 | ≥ 1.25 倍 | 恒定 |
| 悬停 / 按下反馈 | ≥ 1 种（阴影或边框变化） | 存在指针设备 |
| 卡内主操作数 | ≤ 1 | 恒定 |
| 返回行为 | 恢复滚动位置 + 筛选状态 | 从卡片进入详情时 |

> 以上是推导结论，不是法律。当意图判读改变时，需重新走第 2 段。
